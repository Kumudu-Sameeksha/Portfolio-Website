🌐 Personal Portfolio Website

I'm excited to share my Personal Portfolio Website, a project that reflects my journey as a BSc (Honours) Software Engineering undergraduate and showcases my passion for creating modern, responsive, and user-friendly web applications.

This portfolio serves as a central hub where recruiters, hiring managers, and fellow developers can learn more about my technical skills, projects, education, certifications, and professional growth. My goal was to design a clean, visually appealing, and responsive website that highlights both my frontend development abilities and my interest in UI/UX design while providing an enjoyable browsing experience across all devices.

The website features a modern interface with dedicated sections for About, Technical Skills, Featured Projects, Education, Certifications, and Contact Information. It also includes direct access to my GitHub repositories and LinkedIn profile, making it easy for visitors to explore my work and connect with me professionally.

✨ Key Features

• Responsive design for desktop, tablet, and mobile devices
• Clean, modern, and intuitive user interface
• Professional About section
• Technical Skills showcase
• Featured Projects with detailed information
• Education and Certifications section
• Contact form and social media integration
• Smooth scrolling navigation and interactive UI components
• Optimized layout for an improved user experience

🛠️ Technologies Used

• HTML5
• CSS3
• JavaScript (ES6)
• Responsive Web Design
• Git & GitHub
